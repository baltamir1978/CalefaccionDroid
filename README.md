# CalefaccionDroid

Controla la calefacción de varias casas con termostato Netatmo desde una sola pantalla, con widgets y mosaicos de Ajustes rápidos («Tengo frío»).

Versión para Android de [Calefacción Netatmo](https://github.com/baltamir1978/calefaccion-netatmo), la app de iOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Kotlin + Jetpack Compose, para **Android 12 o posterior**.
